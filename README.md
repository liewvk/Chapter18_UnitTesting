# Chapter 18: Unit Testing

A C++ project demonstrating unit testing practices and techniques.

## Overview

This repository contains examples and exercises from Chapter 18 covering unit testing in C++. The project includes test cases and implementations to learn best practices for writing and organizing unit tests.

## Project Structure

- **Source files**: C++ implementation files
- **Test files**: Unit test cases
- **CMake configuration**: Build system setup

## Technologies

- **Language**: C++ (92.2%)
- **Build System**: CMake (7.8%)

## Building the Project

```bash
mkdir build
cd build
cmake ..
make
```

## Running Tests

After building, run the tests with:

```bash
ctest
```

Or execute the test binary directly from the build directory.

## Requirements

- C++ compiler (C++11 or later)
- CMake 3.10 or higher
